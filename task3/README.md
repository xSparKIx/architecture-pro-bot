# Векторный индекс базы знаний QuantumForge

## Описание проекта

Создание векторного индекса для внутренней базы знаний QuantumForge Software с использованием RAG-архитектуры.

## Используемые технологии

### Модель эмбеддингов
- **Название**: `paraphrase-multilingual-MiniLM-L12-v2`
- **Репозиторий**: https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
- **Размерность**: 384
- **Особенности**: 
  - Оптимизирована для поиска семантически близких предложений (перефразировок, синонимичных высказываний).
  - Работает с более чем 50 языками, включая русский, английский, китайский, немецкий, французский и многие другие. Ключевое преимущество — она сопоставляет смысл между языками (кросс-лингвально). То есть вектор для "Hello" будет близок к вектору для "Привет".
  - Облегченная архитектура, производная от моделей типа BERT/RoBERTa. Она сохраняет высокое качество, но значительно меньше и быстрее благодаря дистилляции (обучению у "учителя").

### Векторная база данных
- **Тип**: ChromaDB
- **Режим**: Сохранение на диске
- **Метрика расстояния**: Косинусное сходство
- **Преимущества**: 
  - Встроенное хранение метаданных
  - Простой API
  - Поддержка фильтрации

### Обработка документов
- **Чанкинг**: Рекурсивное разбиение по семантическим границам
- **Размер чанка**: 500 токенов
- **Перекрытие**: 100 токенов
- **Сохранение**: Полные метаданные источника и позиции
