Бот перестал выдавать чувствительные данные и начал отвечать, что он не может рассказать такую информацию.
Также была добавлена проверка в сам запрос, которая предварительно проверят вопросы пользователя прежде чем передавать их в бота.

## Удаление системных конструкций типа
Был добавлен фильтр, который не включает в индексацию документы с потенциально опасными словами.

## Потенциальные уязвимости:
- Сложность обнаружения: Sophisticated prompt injection может обойти простые фильтры
- Контекстные утечки: LLM может "догадаться" о чувствительной информации по контексту
- Эвристические ограничения: Фильтры на ключевых словах имеют ограниченную эффективность

## Рекомендации по улучшению:
- Многоуровневая защита: Комбинация pre, during и post-processing фильтров
- ML-based детекция: Использование моделей для обнаружения prompt injection
- Контекстуальный анализ: Проверка семантики запросов, а не только ключевых слов
- Аудит и логирование: Детальное отслеживание всех подозрительных запросов
- Регулярное обновление: Паттерны атак постоянно эволюционируют
